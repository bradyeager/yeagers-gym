# Billing privacy boundary

Billing automation and operational records are maintained in the private bradyeager/yeagers-gym-billing repository. The public website repository must not contain client billing records, schedules, receipts, ledgers or raw events.

The public history was cleaned on October 17, 2026. Use a fresh clone before making website changes. Do not merge or push an older clone or archive into this repository; it can restore removed private history.

Historical implementation and recovery evidence are preserved privately. This page is a routing notice, not an executable billing or checkout procedure.
