# Public repository — no client context

This repository is **public**. Anything committed here is world-readable.

Do not commit to this repo:

- client context, training history, health information, or personal details;
- credentials, API keys, tokens, or connection strings.

Project facts, coaching doctrine, and per-client context live in the private
JARVIS Brain, not in this repository. Read them there.

A prior instruction file at this path was removed because it contained client
context that must not be public.
